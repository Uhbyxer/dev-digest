# skill-evals/_shared

Спільна конвенція для eval-ів проєктних скілів. Тут немає даних жодного
конкретного скіла — тільки правила й (майбутній) раннер.

## Конвенція

Eval скіла живе **всередині самого скіла**, щоб їхати разом із ним при
`/plugin`-пакуванні чи копіюванні скіла в інший проєкт:

```
.claude/skills/<skill>/
├── SKILL.md, references/...
└── evals/
    ├── eval.md                  task-промпти + критерії оцінки + пороги
    ├── expected-findings.json   еталон: file / line / rule (+ must_not_flag)
    └── fixtures/                код для перевірки, БЕЗ коментарів-підказок
```

Правила:
- у `fixtures/` ніяких підказок про порушення (коментарі, назви файлів, `TODO`);
  відповіді тільки в `expected-findings.json`;
- у фікстурі завжди є чисті файли-приманки (`must_not_flag`) — міряємо і recall, і хибні спрацювання;
- реєстрація не потрібна: додати eval скілу = створити йому `evals/`.
